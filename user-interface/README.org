The User Interface is the source-owned composition surface for vertical
knowledge.  Its direct children have fixed responsibilities:

| Path | Responsibility |
|------+----------------|
| =init.ss= | Module enablement only. |
| =modules/= | User-owned modules not admitted as public contributions. |
| =profiles/= | Reusable, inheritable POO Profile objects. |
| =scenarios/= | Vertical boundaries, their Profiles and concrete Cases. |

=init.ss= selects the Ontology module.  POO Flow owns discovery, admission and
composition; this repository does not maintain a second loader or registry.

Ontology Profiles declare named =.import=, =.add-concept=, =.add-relation=,
=.add-source=, =.add-rule= and =.add-query= slots.  Scenarios declare identity
and a base Profile.  Cases select Profiles, add Case-local Sources and build
topology through the POO Flow Graph prototype.  Derived projections are not
maintained as parallel user bindings.

Healthcare, commercial finance, manufacturing, education and software
engineering are vertical knowledge Scenarios.  They reuse the Ontology module;
none is a top-level module or a second assurance engine.

ADR, GitOps and software-lifecycle assurance live in Lambda Aitia.  This tree
does not provide compatibility namespaces for those modules.
