# Exchange Signing Case Rules

- Preserve observed, reported, and hypothetical material as distinct inputs. A model route or TLC counterexample is not a historical incident fact.
- Author competing investigation directions as POO branches. Replay every branch against every hypothesis; do not hard-code a single "next" step, winner, or incident probability from missing claims or illustrative weights.
- Keep Agent collection options free of tool binding and execution authority. A Host must authorize a tool, bind the source artifact, and admit evidence before a real-world conclusion or effect is considered.
- A claim-supplied content digest identifies an asserted artifact; it does not authenticate its source or eliminate the Host source-binding task. Preserve distinct digest and independence-group claims for review.
- Claims without a source reference must produce a visible source-artifact collection task; they cannot silently enter the Agent brief as sourced evidence.
- Keep incident-specific evidence and collection questions in this Case. Put reusable inference semantics in POO Flow.
- Qualify changes with the Case's `just check-chain` gate and inspect the Scheme harness markers, not only its exit status.
