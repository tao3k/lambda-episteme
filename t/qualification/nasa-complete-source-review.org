#+title: NASA source review completion and warm-build root cause
#+date: 2026-09-12

* Source baseline and implemented scope
Official NODIS NPR 7150.2D Chapter 2–5 snapshots supply the normative
paragraphs for every one of the 130 indexed SWE requirements. Appendix C
supplies 100 class/authority matrix rows; the remaining 30 are institutional.
The catalog now preserves 255 paragraph-level criteria and separate notes,
including subsection 5.2 (SWE-086), which has no numbered requirement paragraph.
The importer asserts exact source/matrix identity and section agreement and
regenerates byte-for-byte identically. Chapter 6 is retained for documentation
guidance, not counted as additional mandatory SWE requirements.

* Review behavior
- All project matrix rows have explicit or unconditional applicability behavior;
  fully supplied test context leaves no unsupported project-condition branch
  for any of the six software classes. Missing conditions still yield unknown.
- SWE-131 is conditional on required IV&V, unlike SWE-178/179's performed IV&V.
  Project category and payload risk classification are distinct from software class.
- Project and institutional review scopes are separate. Each normative paragraph
  requires source-digest-bound, revision/scope/criterion-bound evidence. A pass
  for an introductory sentence does not discharge its subparagraphs.
- Current reported failures override passes. Old source digests or baselines
  cannot satisfy criteria; foreign subjects/scopes are excluded. Duplicate IDs
  and unknown criteria fail validation.
- Safety review checks 100% MC/DC and complexity <=15 for supplied safety-critical
  components. Unknown data remains unknown; complexity exceedance requires review.
- Tailoring records bind to a request, subject, revision, scope and clause.
  Matrix authority roles, cybersecurity involvement and health/medical scope
  remain explicit. Complete claimed records still require authority verification.

* Native validation
Final current-source builds passed for both module and user-interface lanes.
The independent contribution runner passed 405 unit checks, 73 user-interface
checks, and 12 optional GQL source checks (490 total). The separate parent UI
integration passed 4 checks. New native CLOS models reuse inherited identity,
clause and snapshot constraints. No GQL executor or Python runtime is introduced.

An intermediate user-interface import failure identified stale .ssi files in
the isolated validation output. The copied source had preserved timestamps
older than artifacts compiled from the previous snapshot. The current source
was recopied with current write timestamps, rebuilt, and all lanes rerun.
Only the final successful runs above are counted.

* Performance root cause
The upstream PackageSpec catalog projection took about 0.015 seconds. An
isolated source-expansion probe attributed 18.393 seconds of 19.993 seconds
to nasa-7150-2d-catalog.ss. The old generator emitted a complete .o form for
each row, and std/make expands sources even when outputs are current.

The generator now emits one shared native POO row constructor and quoted
source data. The same probe measured 0.245 seconds for that catalog and 2.113
seconds for all then-existing module expansions, despite including full source
paragraphs. This fixes repeated macro work rather than bypassing freshness,
adding a scheduler, or introducing an alternate build cache.

The native rebuild probe changed only the isolated ADR types source and then
restored its bytes. Both runs rebuilt ADR types, funs, config and interface;
they exited successfully. Thus changed source still triggers native work.

* Explicit limits
This completes indexed source-paragraph review coverage, not a proof that every
natural-language requirement or referenced NASA standard has been satisfied.
Evidence content, signer authority/delegation, project classification, declared
scope completeness, and signature authenticity require independent verification.
The module never certifies NASA compliance or authorizes a release. The whole
POO Flow release/install suite was not evaluated by these independent lanes.
