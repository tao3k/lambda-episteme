#+title: Lambda Episteme native package qualification
#+date: 2026-09-17

* Current source boundary

Lambda Episteme publishes decision-kind, Diataxis, Healthcare and Ontology
module interfaces. POO Flow's contribution registry owns checkout discovery and
maps those four public modules to the pinned child source. ADR, GitOps, SDLC and
NASA lifecycle ownership resides in Lambda Aitia. The Episteme child package
does not implement a second source registry, compiler, scheduler or cache.

* Current build evidence

The native contribution build projects 42 targets through the ASP Build API and
=std/make=. The source-collection qualification discovers exactly the four
public module interfaces, verifies the official contribution expansion and
checks that the selected ontology module resolves to the Episteme source owner.

On 2026-09-17, verification overlapped edits from another session: Healthcare
sources acquired new modification times while immediate build replays were in
progress.  Those replays therefore cannot establish a =std/make= invalidation
defect or a convergence count.  After source edits stopped and the dependency
closure settled, the final build projected the same 42-target closure in 4.861
seconds and emitted zero compile rows.  This is the valid final warm receipt;
the overlapping and still-converging runs are excluded from performance claims.

The complete Lambda Scheme suite discovered eleven test files, dispatched
eleven parallel batches and completed every batch.  The focused Governance
module test also completed in approximately 3.3 seconds and exercised both
accepted module families and a rejected mismatched family through the POO
Flow-owned config admission function.

The Ontology required-relation rule now builds one native hash index of covered
edge endpoints and scans domain nodes once.  A deterministic 1,000-node A/B
receipt counts 500,499 edge comparisons for the superseded nested scan versus
2,000 node-and-edge visits for the indexed path, a greater than 250-fold
operation-count reduction.  The executable 10,000-node and 9,999-edge Scenario
reported p95 =6.287813ms= and maximum =7.065773ms= across 20 samples, below its
40ms target and 100ms maximum, with zero measured heap and live-memory growth
after the benchmark GC precondition.

* Limits

These checks establish package structure, source ownership and native import
closure only. They do not authenticate evidence producers, execute external
services, certify regulatory compliance or authorize effects.
